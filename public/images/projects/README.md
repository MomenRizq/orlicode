# صور المشاريع

حط هنا صورة كل مشروع حقيقي هتضيفه للموقع.

## طريقة الاستخدام

1. حط صورة المشروع في المجلد ده (مثلاً: `atlas-crm.jpg`).
2. المقاس المفضل: `1400x788` بكسل (نسبة 16:9) وحجم أقل من 500KB عشان الموقع يفضل سريع.
3. الصيغ المدعومة: `.jpg` أو `.png` أو `.webp`.
4. في ملف `src/data/projects.ts`، حط مسار الصورة في حقل `image` بالشكل:
   ```
   image: "/images/projects/atlas-crm.jpg",
   ```

بعد ما تحط الصور هنا، روح على `src/data/projects.ts` وضيف بيانات المشروع (الاسم، الوصف، اللينك، التقنيات المستخدمة...) زي الشرح الموجود فوق المصفوفة `projects`.
